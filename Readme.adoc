# Readme for 'My Raytracing Challenge'
:author: Willy Clarke

== Project description

The 'Ray Tracer Challenge' is a book by Jamis Buck. It contains a specification on how to
build a raytracer, driven by tests. The code in this repository is my attempt to learn
about raytracing in general — implemented, so far, in three programming languages, each
with its own Readme:

.The Appendix A1 cover scene from _The Ray Tracer Challenge_ by Jamis Buck, rendered by the Rust implementation, link:RUST/rtc-rust/README.md[RUST/rtc-rust].
image::RUST/rtc-rust/docs/cover.jpg[Cover scene rendered by rtc-rust,800]

== Implementations

* *C++* — `Cpp`: the original implementation; built with CMake and tested with
  Google Test. See link:Cpp/Readme-cpp.adoc[Cpp/Readme-cpp.adoc].

* *Rust* — `RUST/rtc-rust`: complete through chapter 17, the three online bonus chapters,
  and the Appendix A1 cover image. Ships an `rtc` CLI that renders JSON scene descriptions
  (with man-style built-in help) and Python generators for example scenes. See
  link:RUST/rtc-rust/README.md[RUST/rtc-rust/README.md].

* *Zig* — `ZIG/raytracer-zig`: work in progress, currently around chapter 10 (patterns).
  See link:ZIG/raytracer-zig/README.md[ZIG/raytracer-zig/README.md].
