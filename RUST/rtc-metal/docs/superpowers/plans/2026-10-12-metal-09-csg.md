# rtc-metal milestone 9: CSG and the perturbed pattern — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render rtc-rust's dice scenes on the GPU: book chapter 16 CSG plus rtc-rust's perturbed (Perlin) pattern.

**Architecture:** One new `u32` buffer, `tables`, holds the Perlin permutations and the CSG programs. Each CSG root becomes one `SHAPE_CSG` BVH entry whose leaves sit behind the BVH-indexed shapes. The shader collects every leaf root, sorts it, and keeps a root iff flipping that leaf's inside bit changes the postfix-evaluated membership of the tree. Perturbed materials carry a second (base) pattern inverse and a permutation offset.

**Tech Stack:** Rust 2024, objc2-metal 0.3.2, MSL compiled at runtime, rtc-rust as path dependency and CPU reference.

**Spec:** `RUST/rtc-metal/docs/superpowers/specs/2026-10-12-metal-09-csg-design.md`

## Global Constraints

- All commands run from `RUST/rtc-metal` unless noted. Tests: `cargo test --release`. Lint: `cargo clippy --release --all-targets` must report 0 warnings; run `cargo fmt` before each commit.
- Rust structs in `types.rs`/`probes.rs` mirror MSL structs byte for byte; every size change updates both the Rust `const _: () = assert!(size_of::<…>() == N)` and the MSL `static_assert`.
- `GpuMaterial`/`Material`: 144 → 224 bytes. `GpuShape`/`Shape`: 320 → 400 bytes. Every probe struct embedding either grows by 80.
- `tables` binds at `[[buffer(4)]]` in `render` (and the `Accumulator`), at `[[buffer(5)]]` in every `run_with_scene` kernel. An empty `tables` uploads one zero word.
- Constants (same values in `types.rs` and `rt.metal`): `SHAPE_CSG = 6`; `CSG_LEAF = 0`, `CSG_UNION = 1`, `CSG_INTERSECTION = 2`, `CSG_DIFFERENCE = 3`; `NOISE_NONE = 0xffff_ffff`; `CSG_MAX_LEAVES = 32`; `CSG_MAX_HITS = 64`.
- Max roots per leaf kind: sphere 2, cube 2, plane 1, triangle 1, cylinder 4, cone 4.
- Rejection messages, each prefixed `shape {id}: `: `transparent CSG leaves are not supported yet`, `groups inside a CSG are not supported yet`, `motion is not supported yet`, `a CSG with over 32 leaves is not supported yet`, `a CSG with over 64 intersections is not supported yet`. Pattern: `only stripe, gradient, ring, checkers and perturbed (over one of those) patterns are supported so far`.
- Test names: CSG `test_chap_16_…`, noise/perturbed `test_chap_17_…` (rtc-rust's numbering for them).
- The only rtc-rust change is `Perlin::permutation`. Run `cargo test --release` in `RUST/rtc-rust` after it.
- Commit after each task with the repo's `ENHANCEMENT:`/`TEST:`/`DOCS:`/`FIX:` prefix style and the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push. Merge into develop only when the user asks.

## Review Focus

1. **Ray starting inside a CSG solid** (shadow rays from a die's surface, reflections inside a pip dimple): negative-t roots must still toggle bits, or the over_point's shadow ray sees the die's own far side as a boundary. Pinned in Task 5, step 1 (`test_chap_16_gpu_trace_ray_inside_csg`).
2. **CSG inside a transformed group** (dice-sentence nests each letter's dice in a root group): leaf transforms must include the group's transform. Pinned in Task 3, step 1 (`compile_csg_composes_parent_transforms`).
3. **Negative noise coordinates**: `int(floor(x)) & 255` must equal rtc-rust's `(x.floor() as i64 & 255)` for x < 0. Pinned in Task 2, step 1 (points span −20..20).
4. **Two materials sharing a seed**: one permutation in `tables`, not two; distinct seeds get distinct offsets. Pinned in Task 2, step 1 (`tables_intern_noise_by_permutation`).
5. **Scene with CSG but no other bounded shapes / empty BVH**: CSG entries are bounded, so they enter the BVH; a scene of only a CSG still renders. Pinned in Task 5, step 1 (book scenarios have no floor).
