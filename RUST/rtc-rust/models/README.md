# models

OBJ meshes used by the chapter 16 render tests.

The committed files are generated by `generate.py` in this directory and are
covered by the repository's MIT license (see `LICENSE` at the repo root):

- `icosahedron.obj` — 12 vertices / 20 faces, no normals → flat shading
  (`test_chap_16_6`)
- `torus_smooth.obj` — torus with analytic `vn` vertex normals → smooth
  shading (`test_chap_16_smooth_torus`)

To regenerate: `python3 generate.py`

Any other files in this directory (e.g. meshes downloaded from the internet
for local experiments) are gitignored and never committed.
